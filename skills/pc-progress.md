# 电脑进度速查 & 接着做

## 1. 读进度

- 先 `mcp__pc__sessions`，参数 `only_active: true`（只看在跑 / 等你确认的）。
- 没有活跃的就再调一次 `mcp__pc__sessions`（`limit: 5`）看最近的。
- 对每条「🔄进行中」或「⚠️等你确认」的会话，调 `mcp__pc__session_progress`（`tail: 4`）。
- 远程派活的任务型会话另配 `mcp__pc__list_tasks` / `mcp__pc__task_log`。

## 2. 报（中文简报，一次最多 3 条会话）

每条说清：在干什么（标题 + 目录）· 进度（待办 x/y、正在做的那一项）· 状态（进行中 / 已结束第几轮 / 等你拍板）· 最后活动多久前 · 产出文件（最多 3 个）。
若是「等你确认」：把问题和 A/B/C 选项**原样**列出来，然后问用户选哪个。

## 3. 接着做（重点）

用户说「**在电脑那条会话里说……**」「**让电脑接着做**」「**继续刚才那个**」时：

1. 先确定是哪条会话（见下）。
2. 调 `mcp__pc__session_send`：
   - `id`：会话 id（从 `sessions` 拿）
   - `text`：用户要传的话（比如"把测试跑一遍，跑完告诉我结果"）
   - `mode`：默认 `queue`（排队执行）；用户明确要**打断当前这一步插话**时才用 `steer`
3. 回报一句话：「已发进电脑那条会话《标题》，电脑开始跑了」，并给出会话标题。
4. 用户之后问进度 → 回到第 1 步用 `session_progress` 复查；别自己编进度。

## 4. 选哪条会话（别猜错）

- 用户点名了标题 / 关键词 → 用 `sessions` 的结果按标题匹配。
- 用户没说 → 若只有一条活跃会话，直接用它并说明"我给你发到《标题》这条了"；有多条就列出来让他选。
- 用户说的和列表对不上 → 直接把会话列表给他，别硬凑。

## 5. 克制

- 只给结论，不要复制工具原始输出、不要贴长日志。
- 一次最多 3 条会话；用户没问就别主动汇报。
- 状态拿不准（文件刚变、可能正在写）就说"可能还在写"。
